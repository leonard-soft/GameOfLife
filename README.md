*A Pure JavaScript Implementation*

Welcome to this interactive version of Conway’s Game of Life, the legendary cellular automaton devised by mathematician John Horton Conway in 1970.

🔹**What is it?**

A zero-player "game" where patterns evolve through simple rules:

**Birth:** A dead cell revives with exactly 3 living neighbors.

**Survival:** A living cell survives with 2 or 3 neighbors.

**Death:** By loneliness (<2 neighbors) or overcrowding (>3 neighbors).

🔹 **Features of this version:**

✔ Built without external libraries (pure HTML, CSS, and vanilla JavaScript).

✔ Intuitive controls: play/pause, reset, and speed adjustments.

✔ Custom patterns: Draw your own shapes and watch them evolve!

**🚀 How to start?**

Click cells to toggle them on/off.

Hit "Start" to unleash emergent chaos (or order).

Try classic patterns like the Glider or Pulsar.
